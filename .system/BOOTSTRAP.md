# System restore runbook

Rebuilds this setup on a fresh **CachyOS** install (GRUB + LUKS, btrfs).
Nothing here is one-click by design — follow top to bottom.

## 1. Dotfiles (bare repo)

```fish
git clone --bare git@github.com:fbeam2206/.dotfiles.git $HOME/.dotfiles
alias dotfiles='git --git-dir=$HOME/.dotfiles --work-tree=$HOME'
dotfiles config status.showUntrackedFiles no
dotfiles checkout        # add -f to clobber fresh-install defaults
```

The `dotfiles` alias is also defined permanently in `~/.config/fish/config.fish`
once the checkout lands.

## 2. Packages

```fish
sudo pacman -S --needed - < ~/.system/pkglist.txt
paru -S --needed - < ~/.system/aurlist.txt
xargs flatpak install -y flathub < ~/.system/flatpaklist.txt
```

Notes:
- `pkglist.txt` assumes the CachyOS repos (present on any CachyOS install);
  `mullvad-vpn` comes from there too.
- All three lists are auto-regenerated by a pacman hook
  (`etc/pacman.d/hooks/pkglists.hook` → `usr/local/bin/pkglists-refresh`),
  so they are always current as of the last pacman transaction on the old
  machine. Flatpak changes only refresh on the next pacman run.

## 3. System files

```fish
sudo bash ~/.system/install.sh
```

Installs: udev rules (Pulsar X2V3 mouse, Wooting), the package-list pacman
hook, and cs2-shield (via its own installer in `~/.local/share/cs2-shield/`,
including enabling `cs2-shield-auto.service`).

## 4. GRUB kernel parameters (manual merge — do NOT copy the file)

Merge these into `GRUB_CMDLINE_LINUX_DEFAULT` in `/etc/default/grub`, keeping
whatever `cryptdevice=`/`root=` the new installer wrote (those UUIDs are
per-disk):

```
mitigations=off nowatchdog nvme_load=YES zswap.enabled=0 splash loglevel=3
```

Then `sudo grub-mkconfig -o /boot/grub/grub.cfg`.
Old machine's full file: `reference/etc-default-grub`; booted cmdline:
`reference/kernel-cmdline.txt`.

## 5. Neovim config (separate repo)

```fish
git clone git@github.com:fbeam2206/neovimconfig.git ~/.config/nvim
```

## 6. scratchWS python venv (not tracked — 23 MB, regenerable)

`~/.config/hypr/scripts/scratchWS.py` expects a venv **in the scripts dir**:

```fish
python -m venv ~/.config/hypr/scripts
~/.config/hypr/scripts/bin/pip install hyprpy
```

## 7. Manual checklist (nothing below lives in a file)

- **BIOS**: C-states **disabled** (deliberate latency tune — no cpuidle
  driver). Keep this list updated when changing other BIOS settings (XMP,
  fan curves, ...).
- **Mullvad**: log in (`mullvad account login <number>` — account number is
  in KeePassXC). Split-tunnel exclusion is wired via
  `mullvad-exclude steam ...` in Hyprland's `execs.conf` (already tracked).
- **Steam**: log in; games re-download. CS2 launch options (per-machine, not
  cloud-synced):
  `~/.config/hypr/scripts/game-mode.sh %command% -high -nojoy -refresh 360`
- **Monitors**: DP-5 = 1440p@360 primary, HDMI-A-5 secondary (handled by
  hypr config), plus any monitor-OSD settings.
- **Enabled services**: `reference/enabled-services.txt` is a snapshot from
  the old machine for cross-checking; most enablement comes from packages
  and `install.sh`.

## Explicitly NOT covered (separate encrypted backup — TODO)
